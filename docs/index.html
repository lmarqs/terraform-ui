Features

From plan to apply, in one keyboard

Every screen below is a real recording of tfui on the same sample plan.

{% include icons/list-tree.svg %}Plan tree

Expand the diff, not the scrollback

Navigate changes as a tree. Press enter on a row to read its attribute diff. Filter by address with /.

{% include icons/shield-alert.svg %}Risk

Know the blast before you apply

  • [CRITICAL]
  • [HIGH]
  • [medium]
  • [low]

Rules know your resources. Destroying a database is critical. Changing an IAM role is high. Changing an instance is low.

How risk is classified{% include icons/arrow-right.svg %}

{% include icons/pin.svg %}Pin and apply

space to pin, a to apply

Pin the resources you care about. tfui replans with them as targets, shows you exactly what will happen, and asks once. No -target flags to type, no copy-paste mistakes.

The apply plugin{% include icons/arrow-right.svg %}

{% include icons/database.svg %}State

Search state, change it with a prompt

Fuzzy-search hundreds of resources and inspect their JSON. Taint, untaint, import, move and remove each wait for confirmation, so a typo never runs.

The state plugin{% include icons/arrow-right.svg %}

{% include icons/ghost.svg %}Phantom changes and blast radius

Tell noise from impact

Terraform says "1 to change" and nothing changes: null versus absent, a reordered list, provider normalization. tfui marks those as phantom. Blast radius groups the real changes by module and scores how far each one reaches.

{% include icons/ghost.svg %}

Phantom changes

Null versus absent, list order, provider normalization: the causes tfui recognizes, and how it marks each one.

 {% include icons/radar.svg %}

Blast radius

Changes grouped by module, scored by how many resources each touches and how risky they are.

Headless

{{ ba.agent_tokens }} tokens instead of {{ ba.before_tokens }}

When Claude Code runs tfui plan, it gets every change address, the summary and a risk verdict in a fraction of the tokens. Nothing to configure.

  1. Detects the agent

    CLAUDECODE, AI_AGENT or CI in the environment, or a stderr that isn't a terminal.

  2. Skips the TUI

    No alt-screen, no spinner, no escape codes. One line per change on stdout.

  3. Never claims success on failure

    Terraform's error goes to stderr, stdout stays empty, and the exit code is 1.

  4. Exits with meaning

    0 no changes, 2 changes present, 1 error. The agent branches without reading a byte.
