# Experimental pin review

Inspected 2026-11-15. The experimental pin is OPA **v1.19.1**, revision `54896f9f28515d14b31a93e6ef5737bb85866e30`, for testing compatibility with repository Go1.25.5. This is a preparation choice, not dependency adoption or security approval.

The [current upstream releases page](https://github.com/open-policy-agent/opa/releases) identifies v1.22.4 as latest. Its [immutable release](https://github.com/open-policy-agent/opa/releases/tag/v1.22.4) points to revision `ba39415db4b3c90cd68942a74b3cc2223ec2b23c`, released November 12. The [revision's go.mod](https://raw.githubusercontent.com/open-policy-agent/opa/ba39415db4b3c90cd68942a74b3cc2223ec2b23c/go.mod) declares Go1.26.0. This conflicts with the experiment's fixed Go1.25.5 toolchain. Release notes describe an upstream-binary Go HTTP-server vulnerability fix and explicitly distinguish builds made with one's own Go version; they do not establish safety for our embedding.

The [v1.19.1 release](https://github.com/open-policy-agent/opa/releases/tag/v1.19.1) is immutable and resolves to [the pinned revision](https://github.com/open-policy-agent/opa/commit/54896f9f28515d14b31a93e6ef5737bb85866e30). Its [go.mod](https://raw.githubusercontent.com/open-policy-agent/opa/54896f9f28515d14b31a93e6ef5737bb85866e30/go.mod) declares Go1.25.0. The August 17 patch notes describe rebuilding upstream binaries with Go1.26.6 for standard-library fixes; OPA implementation code otherwise matches v1.19.0. Embedding with Go1.25.5 does not inherit the upstream binary's compiler fixes. Declared compatibility alone says nothing about the transitive graph.

The [v1.20.1 module](https://raw.githubusercontent.com/open-policy-agent/opa/v1.20.1/go.mod) also declares Go1.26.0. The [v1.15.1 release](https://github.com/open-policy-agent/opa/releases/tag/v1.15.1) describes a Logger interface compatibility fix over v1.15.0; it is a historical comparison lead, not a fallback selected by this preparation. The original repository research inspected v1.15.0 at `f9e7302d69595f413840344bd642653d2a99766e` and remains historical API evidence. This task did not verify every intervening release or establish that v1.19.1 is the newest Go1.25-compatible patch.

The [official security policy](https://www.openpolicyagent.org/security) describes fixes for releases under maintenance but provides no version support table. A past patch is evidence of maintenance activity at its release, not proof that v1.19 is currently supported. No complete advisory inventory, dependency audit or vulnerability scan was performed. Those remain review inputs before any production choice. Current release review supports testing this older toolchain-motivated candidate; it does not support calling it current, secure or accepted.

Source access: official GitHub releases/latest API retrieval failed on retry; the release HTML and immutable linked commits supplied the latest observation. Raw v1.22.4 tag URL and pinned v1.19.1 rego API source fetches returned cache misses; revision-pinned v1.22.4 go.mod succeeded. Consequently exact v1.19.1 option implementation review remains required before harness execution; protocol controls are proposals. No downloaded code or module resolution was executed.
