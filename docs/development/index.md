## Documentation Site Structure

The docs site at `docs/` is a Jekyll site published to GitHub Pages by `.github/workflows/pages.yaml`. It uses its own theme: two layouts, a few includes, one stylesheet and one script, with no theme gem.

```
docs/
├── index.html                # Landing page (layout: home)
├── _config.yml               # Site settings and plugins
├── _data/
│   ├── nav.yml               # The sidebar, in reading order, with each page's sidebar title
│   └── pins.yml              # The numbered pins on the landing illustration and their legend
├── _layouts/
│   ├── default.html          # Every Markdown page: top bar, sidebar, content, "On this page"
│   └── home.html             # The landing page
├── _includes/
│   ├── context.html          # Resolves page_title and section from _data/nav.yml
│   ├── head.html, title.html, header.html, sidebar.html, footer.html
│   └── icons/                # Inline SVG icons: Lucide and Simple Icons
├── assets/
│   ├── site.css              # The theme, dark and light schemes
│   ├── site.js               # Heading anchors, page contents, copy buttons, landing pins, search
│   ├── fonts/                # Space Grotesk and JetBrains Mono, self-hosted
│   ├── base.webp             # Landing illustration
│   └── demo/                 # Demo GIFs, generated by demo/generate.sh
├── guides/  features/  plugins/  reference/  development/  adr/
└── roadmap.md
```

### Pages and the sidebar

- A Markdown page renders with the `default` layout. Its `description` front matter becomes the search-engine and link-preview description.
- To list a page in the sidebar, add its `path` and `title` to `_data/nav.yml`. A `match` folder marks the entry current for every page under it, as `adr/` does for the decision records.
- Link between pages with relative `.md` paths, such as `[Apply](../plugins/apply.md)`. `jekyll-relative-links` turns them into site URLs.
- Plugin pages carry `id`, `key`, `category` and `default_enabled` front matter.

### Icons

Icons are inline SVG includes that draw in the color of the text around them: `{% raw %}{% include icons/terminal.svg %}{% endraw %}`. Brand icons come from [Simple Icons](https://simpleicons.org) (CC0); the rest from [Lucide](https://lucide.dev) (ISC, see `_includes/icons/LICENSE-lucide`). A new icon takes its markup from the same package, in the form of the icons already there.

### Build and preview

```bash
mise run docs:install   # once, and after the Gemfile changes
mise run docs:serve     # live preview at http://localhost:4000/terraform-ui/ (no search)
mise run docs:build     # the deployable site in docs/_site, with the Pagefind search index
```

Search is built by [Pagefind](https://pagefind.app) after Jekyll, so it works on `docs:build` output and on the deployed site, not under `docs:serve`. On pull requests the Pages workflow builds the site and runs `htmlproofer` over it without deploying.
